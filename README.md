# 💛💙 Fenerbahçe Maç Bildirim Botu
**Fenerbahçe'mizin tüm futbol maçlarını anlık olarak takip edin!**

### ✨ Özellikler:
- 📣 **Hatırlatmalar:** 'Yaklaşan maç günü' bildirimi ve maç günü geldiğinde sabah hatırlatması.
- 📋 **Maç Öncesi:** Maçtan hemen önce ilk 11 bilgisi ve 'maç başlıyor' uyarısı. 
- 🏁 **Maç Sonu:** Bitiş skoru & maç özeti linkleri.

# 💛💙 Fenerbahçe Matches Notification Bot
**Follow Fenerbahçe football matches in real time!**

### ✨ Features:
- 📣 **Match Day Alerts:** “Upcoming match day” notification and morning reminder when match day arrives.
